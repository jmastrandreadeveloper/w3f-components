## Convenciones de cada capítulo

Cada capítulo sigue esta estructura:

1. **¿Qué vas a aprender?** — 3 a 5 conceptos clave
2. **Conceptos** — explicación clara con diagramas donde sea necesario
3. **Ejemplos de código** — snippets progresivos de simple a complejo
4. **Ejercicio práctico** — un ejercicio guiado con solución
5. **Referencia rápida** — tabla de props o API del capítulo
6. **Siguiente paso** — link al próximo capítulo

---

## Guía de lectura recomendada

- **Si nunca usaste un UI framework**: empezá por Cap 01 y seguí en orden.
- **Si venís de MUI o Chakra**: leé Cap 01 (sección comparación), luego Cap 02 y Cap 05.
- **Si solo querés los charts**: leé Cap 17 y Cap 18.
- **Si querés crear componentes propios**: leé Cap 04 primero, luego Cap 21.
